# Support

## Getting Help

### Community Support (Free)

- **GitHub Discussions**: Ask questions, share ideas, get help from the community
- **GitHub Issues**: Report bugs, request features
- **Documentation**: Check our comprehensive docs at [docs/](docs/)

### Commercial Support

For enterprise users who need guaranteed response times:

- **Email**: enterprise@sentinel.dev
- **SLA**: 24-hour response time for critical issues
- **Includes**: Priority bug fixes, feature requests, deployment assistance

### Professional Services

- **Custom Development**: Tailored features for your organization
- **Deployment Assistance**: Help with production deployment
- **Training**: Team training on Sentinel usage and development

## FAQ

**Q: How do I get started?**
A: See our [Quickstart Guide](docs/quickstart.md).

**Q: How do I report a bug?**
A: Open a [GitHub Issue](https://github.com/yourusername/sentinel/issues) with the bug report template.

**Q: How do I contribute?**
A: See our [Contributing Guide](docs/contributing.md).

**Q: Is Sentinel free?**
A: Yes, Sentinel is open source under the MIT License. Commercial support is available for enterprise users.
